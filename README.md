# Barber Shop Management

نظام إدارة ومحاسبة لمحل حلاقة، مبني باستخدام React + Vite.

## تشغيل المشروع

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر في Terminal.

## الحالة الحالية

هذه هي النسخة الأولى: واجهة Dashboard احترافية باللغة العربية مع تصميم Dark/Gold ومتجاوبة مع الكمبيوتر والموبايل.

الخطوات القادمة ستكون إضافة الصفحات والبيانات الحقيقية وقاعدة البيانات وتسجيل الدخول.
